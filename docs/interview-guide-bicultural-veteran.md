# 카톡용 — 한국→미국 20년 경력자께 보낼 메시지

> 그대로 복붙해서 보내면 됨. 답장은 편한 만큼만.

---

안녕하세요! 제가 한국-외국 업무 소통에서 자주 오해 생기는 표현들을 정리하는
프로젝트를 하고 있는데, 한국이랑 호주, 미국 양쪽 다 일해보신 분 경험이 제일 정확할 것
같아서 여쭤봐요 🙏

**혹시 "이 말이 이런 뜻인 줄 알았는데 아니었다" 하고 오해하셨던 경험 있으세요?
기억나는 거 1~2개만 편하게 말씀해주시면 돼요.**

예를 들면 이런 것들이요:
- "내일까지 해주세요" 같은 말이 정확히 몇 시까지인지 헷갈렸던 적
- "Review complete" / "확인했습니다" 같은 말이 진짜 승인인지 그냥 봤다는 건지 헷갈렸던 적
- "조금 더 생각해보면 어떨까요" 같은 완곡한 말을 반대인지 그냥 의견인지 헷갈렸던 적
- 회의/마감 시간 관련해서 시차나 문화 차이로 오해 생겼던 적

이런 것 말고 다른 것도 상관없어요, 생각나시는 대로 편하게 알려주시면 감사하겠습니다!

앗 답변 정말 흥미로웠어요! 근데 제가 하나 더 여쭤보고 싶은 게 있는데, 이번엔 진짜
구체적인 문장 5개만 딱 집어서 여쭤볼게요 🙏 한국에서 설문을 돌려보니까 아래
5개 표현 전부 한국 응답자들(12~15명) 사이에서는 해석이 거의 하나로 쏠렸어요 —
그런데 **미국/호주에서도 똑같이 쏠리는지, 아니면 다르게 받아들이는지**가
궁금해서요. 각 문항에 한국 응답 결과도 같이 적어놨으니, 그거 보시고 "어 우리도
그런데?" 인지 "아니 우리는 다르게 받아들이는데?"인지만 편하게 한 줄씩
답해주시면 돼요.

1. 상사가 "일단 이렇게 진행해봐요"라고 했을 때 — 한국에서는 "최종 확정"이
   아니라 "일단 해보고 나중에 다시 논의 가능"으로 압도적으로 읽었어요(7점
   만점에 6.4점). 미국/호주에서도 이렇게 잠정적으로 읽나요?
2. "확인했습니다" / "Confirmed"라고 답장 왔을 때 — 한국에서는 "승인"이 아니라
   "그냥 받았다는 뜻(수신 확인)"으로 압도적으로 읽었어요(5.9점). 미국/호주도
   똑같이 "받았다"는 뜻으로만 읽나요, 아니면 "confirmed"는 좀 더 강한 승인
   느낌인가요?
3. "나중에 다시 얘기해요"라고 했을 때 — 한국에서는 "완곡한 거절"이 아니라
   "시점만 안 정한 보류"로 문자 그대로 압도적으로 읽었어요(6.1점, 거절로 읽은
   건 2.9점뿐). 근데 재밌게도 "이 말을 들었는데 사실 거절이었다"는 실제 경험은
   중간 정도로 있었어요(4.2점) — 기본적으로는 곧이곧대로 믿는데 가끔 뒤통수를
   맞는 셈이죠. 미국/호주에서도 이런 "기본은 믿지만 가끔 아니더라" 패턴이
   있나요, 아니면 애초에 이런 애매한 말을 잘 안 쓰나요?
4. "괜찮은 것 같아요, 근데..." 라고 피드백 왔을 때 — 한국에서는 앞의 칭찬에
   안 속고 "근데" 뒤가 진짜 핵심 수정 요청이라는 걸 압도적으로 알아챘어요
   (5.5점, "근데" 뒤를 놓친 적 있다는 응답도 낮음). 미국/호주에서 누가 이런
   식으로(칭찬 먼저, "근데"로 진짜 피드백) 말하면 그 뒤가 핵심이라는 걸 다들
   아는 분위기인가요, 아니면 앞의 칭찬만 곧이곧대로 받아들이는 사람도 많나요?
5. "This is great, but I think we should reconsider X"라는 영어 피드백을
   받았을 때 — 한국에서는 X를 "참고 의견"이 아니라 "반드시 고쳐야 하는 필수
   사항"으로 거의 만장일치로(6.1점, 표준편차 0.77로 이견이 거의 없음) 읽었어요.
   미국/호주 원어민들도 이 문장을 이 정도로 강하게 받아들이나요, 아니면 진짜
   가벼운 참고 의견 정도로 던지는 표현인가요?
