# 인터뷰 가이드 — 한국→호주 20년 경력자용

> 구글폼(T/F/D 리커트 설문)과 다른 방식. 이분은 한국 근무 경험 + 호주 20년 근무 경험을
> **본인 안에서 직접 비교**할 수 있는 흔치 않은 자원이라, 척도 응답보다 **실제 겪은
> 사건을 자유롭게 끌어내는 반구조화 인터뷰**가 훨씬 값지다. "실제 사건 기반 검증"
> (문헌으로 대체 불가능하다고 확인된 방법, `docs/research-tfd-validation.md` 참고)에
> 해당한다. 소요 시간 약 20분, 녹음/메모 동의 먼저 구할 것, 익명 처리.

## 순서

### 1. 오프닝 (2분)
- 목적 설명: "한국-호주 업무 소통 중 오해가 자주 생기는 표현들을 정리하고 있는데,
  실제로 두 나라에서 다 일해보신 분 의견이 제일 정확할 것 같아서 여쭤봐요."
- 녹음/메모해도 되는지, 익명 처리된다는 것 확인

### 2. 워밍업 (3분)
- 한국에서는 언제까지, 어떤 업계/직무로 일하셨나요?
- 호주로 이주하신 게 몇 년도, 지금 업계/직무는요?
- 지금도 한국 쪽 동료·거래처랑 업무로 소통하는 일이 있으신가요?

### 3. 전체 훑어보기 (5분)
아래 16개 표현을 보여주고(카드나 종이에 인쇄해서 보여주면 더 좋음), **"실제로 이런
비슷한 상황 겪어본 적 있는 거 있으면 체크해주세요"**라고 요청 — 빠르게 스캔하는
단계, 이 시점에 자세히 안 물어봄.

**시간 표현**: "내일까지 부탁드려요" / "빠른 시일 내로" / "가능하면 오늘 중으로" /
"이번 주 중으로" / "곧 다시 연락드릴게요"

**피드백·반대 표현**: "이 방향도 좋은데 조금 더 고민해보면 어떨까요" / "다들 그렇게
생각하시는 것 같아요" / "괜찮은 것 같아요, 근데..." / "This is great, but I think we
should reconsider X" / "I strongly disagree with this approach" / "Can you walk me
through your reasoning?"

**결정 상태 어휘**: "일단 이렇게 진행해봐요" / "Review complete" / "확인했습니다" /
"이견 없습니다" / "나중에 다시 얘기해요"

### 4. 딥다이브 (8분) — 핵심 파트
체크된 것 중 **가장 인상 깊었던 2~3개**를 골라서, 각각:
- 그때 무슨 상황이었나요? (누가, 어떤 메시지를, 어떻게 오해했는지)
- 한국에서 일할 때였다면 어떻게 받아들이셨을 것 같아요?
- 호주에서는(또는 호주 동료는) 어떻게 다르게 받아들이던가요?
- 그 오해가 어떻게 해결됐나요? / 어떻게 해결했으면 좋았을까요?

### 5. 마무리 (2분)
- **이 리스트에 없는데 본인만 겪어본 다른 오해 패턴이 있으셨나요?** (신규 항목
  발굴 기회 — 판단기준표에 21번째 항목으로 추가될 수도 있음)
- 시간대(지리) 관련해서도 비슷한 오해 있었나요? (T축 쪽 실제 사례 보강)

## 기록 양식 (인터뷰 후 정리용)

```
- 항목 ID(해당하면): 
- 실제 상황 요약(익명화): 
- 한국 맥락 해석: 
- 호주 맥락 해석: 
- 신규 항목 여부: 예/아니오
```

정리한 내용은 `docs/문화_판단기준표_초안.md`의 해당 항목 "검증 상태" 칸을 갱신하거나,
완전히 새로운 패턴이면 신규 항목으로 추가하는 데 씀.
