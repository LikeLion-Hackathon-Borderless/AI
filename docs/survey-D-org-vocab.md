# 설문 D — 조직 간 결정 상태 어휘 차이, 구글폼용 문항

> T/F 설문과 스크리닝 질문이 다릅니다 — D축은 "한국 vs 미국" 문화 차이가 아니라
> **"조직마다 용어 쓰는 습관이 다른 것"**으로 재확인됐습니다(`docs/문화_판단기준표_초안.md`
> 3절 참고). 그래서 "한미 협업 경험자"가 아니라 **"여러 조직을 거쳐본 사람"**이면
> 누구나 응답 가능 — 섭외가 훨씬 쉽습니다.

**응답 대상**: 현업 경험자 3명 + 협업/교류 경험 학생 5명(총 n=8 목표) — 인턴/아르바이트
포함 2곳 이상의 조직에 소속돼본 사람 (정규직 아니어도 됨, 국적/영어 무관)
**소요 시간**: 약 5분. **척도**: 1(전혀 아니다)~7(매우 그렇다) 리커트.

---

## 시작 문항 (스크리닝, 필수 2개)

**Q0-a. 지금까지 (인턴/아르바이트 포함) 몇 개의 조직에 소속되어 일해보셨나요?**
- ( ) 1개 이하 (이 설문 대상 아님 — 참고용으로만 답변해도 됨)
- ( ) 2개
- ( ) 3개 이상

**Q0-b. 현재 상태를 선택해주세요**
- ( ) 직장인 (현재 재직 중)
- ( ) 학생 (해외 교류/협업 경험 있음)

---

## D01 — "일단 이렇게 진행해봐요"

> 상사/동료가 위처럼 말했다고 가정하고 답해주세요.

- Q1-1. 저는 이걸 "이 안으로 최종 확정"이라고 이해할 것이다 [1-7]
- Q1-2. 저는 이걸 "1차 시도, 결과 보고 재논의 가능"이라고 이해할 것이다 [1-7]
- Q1-3. 다니던 회사에 따라 이 표현의 의미가 다르게 쓰이는 걸 경험한 적이 있다 [1(전혀없음)-7(매우자주)]

## D02 — "Review complete"

- Q2-1. 저는 이걸 "최종 승인까지 끝남"으로 이해할 것이다 [1-7]
- Q2-2. 저는 이걸 "1차 검토만 끝났고 추가 승인이 필요함"으로 이해할 것이다 [1-7]
- Q2-3. 회사를 옮기고 나서 "완료"/"승인" 같은 말의 뜻이 달라서 헷갈린 적이 있다 [1-7]

## D03 — "확인했습니다"

- Q3-1. 저는 이걸 "승인한다"는 뜻으로 이해할 것이다 [1-7]
- Q3-2. 저는 이걸 "그냥 수신 확인, 아직 검토 전/중"이라는 뜻으로 이해할 것이다 [1-7]
- Q3-3. "확인했다"는 말 때문에 승인된 줄 알았는데 아니었던 경험이 있다 [1-7]

## D04 — "이견 없습니다"

- Q4-1. 저는 이걸 "적극적으로 동의한다"는 뜻으로 이해할 것이다 [1-7]
- Q4-2. 저는 이걸 "특별히 반대할 근거가 없어서 그냥 넘어간다"는 소극적 의미로 이해할 것이다 [1-7]
- Q4-3. 조직마다 "이견 없음"에 대한 무게감이 다르다고 느낀 적이 있다 [1-7]

## D05 — "나중에 다시 얘기해요"

- Q5-1. 저는 이걸 "시점을 정하지 않은 결정 보류"로 이해할 것이다 [1-7]
- Q5-2. 저는 이걸 "완곡한 거절"로 이해할 것이다 [1-7]
- Q5-3. 이 말을 들었는데 사실상 거절이었던 경험이 있다 [1-7]
